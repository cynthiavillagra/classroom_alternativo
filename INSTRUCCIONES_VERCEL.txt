# INSTRUCCIONES PARA DESPLEGAR EN VERCEL

## Opción B1: Autodeploy (SI tienes configurado GitHub + Vercel)
# Vercel debería redesplegar automáticamente después del push
# Espera 2-5 minutos y verifica en:
# https://vercel.com/tu-usuario/tu-proyecto

## Opción B2: Deploy manual (SI ya tienes Vercel CLI instalado)
vercel --prod

## Opción B3: Deploy manual desde el dashboard
# 1. Ve a https://vercel.com/
# 2. Selecciona tu proyecto
# 3. Ve a la pestaña "Deployments"
# 4. Verifica que el último deployment:
#    - Sea exitoso (✅)
#    - Tenga fecha/hora posterior a 18:20 (hora del último commit)
# 5. Si NO hay deploy reciente, haz clic en "Redeploy"

## Después del deploy:
# 1. Espera a que termine (1-3 minutos)
# 2. Abre tu app en Vercel
# 3. Presiona Ctrl+F5 (recarga sin caché)
# 4. Prueba filtrar por "Documentos"
